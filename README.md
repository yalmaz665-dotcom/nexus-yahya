# Nexus Yahya 🚀

**Doğal Dil ile Yapay Zeka Destekli Arayüz Üretim Platformu**

Şirket: **Yahya Almaz Tarafından Yapıldı** © 2024

---

## 📌 Proje Tanımı

**Nexus Yahya**, doğal dil komutlarıyla modern web arayüzlerini ve tam yığın uygulamaları otomatik olarak oluşturan, yapay zeka destekli bir platformdur. Shadcn UI ve Tailwind CSS kullanarak profesyonel kalite kodlar üretir.

---

## ✨ Ana Özellikler

### 🎯 **Arayüz Üretimi**
- ✅ **Doğal Dil ile Arayüz Üretimi** - Türkçe/İngilizce komutlarla UI oluştur
- ✅ **Görsel Düzenleme ve İterasyon** - Sürükle-bırak editörü
- ✅ **Canlı Önizleme (Live Preview)** - Gerçek zamanlı görünüm
- ✅ **Satır İçi Düzenleme (Inline Editing)** - Doğrudan kod değiştir
- ✅ **Özel Tasarım Sistemi Entegrasyonu** - Custom design tokens

### 💻 **Full-Stack Geliştirme**
- ✅ **React ve Next.js Bileşen Üretimi** - Otomatik component scaffolding
- ✅ **API Rotaları Oluşturma** - RESTful/GraphQL endpoints
- ✅ **Veritabanı Entegrasyonları** - PostgreSQL, MongoDB, Prisma
- ✅ **Kimlik Doğrulama (Auth) Yapılandırma** - NextAuth, JWT, OAuth
- ✅ **Çoklu Dosya Yönetimi** - Proje yapısı otomasyonu

### 🎨 **Tasarım & Styling**
- ✅ **Shadcn UI Entegrasyonu** - Premium UI bileşenleri
- ✅ **Tailwind CSS Entegrasyonu** - Utility-first CSS
- ✅ **Responsive Design Desteği** - Mobile-first approach

### 🤖 **Yapay Zeka Özellikleri**
- ✅ **Resimden Kod Üretme (Image-to-Code)** - Screenshot'tan React kodu
- ✅ **Mevcut Kod Tabanı Bağlantısı (Codebase Integration)** - GitHub repo analizi
- ✅ **Akıllı Kod Analizi ve Öneriler** - AI-powered refactoring

### 🚀 **Deployment & Entegrasyon**
- ✅ **GitHub Entegrasyonu** - Push to deploy
- ✅ **Vercel ile Anında Dağıtım** - 1-click deployment
- ✅ **Kod İhracı (Export)** - ZIP, GitHub repo
- ✅ **NPM Paket Desteği** - Component library publish
- ✅ **Proje Çatallama (Forking)** - Şablondan proje oluştur

### 📊 **Versiyon Kontrolü**
- ✅ **Sürüm Geçmişi ve Geri Alma** - Git-based versioning
- ✅ **Git İntegrasyon** - Commit & push automation
- ✅ **Diff Viewer** - Değişiklikleri karşılaştır

## 🛠️ Kurulum & Başlangıç

### Gereksinimler
```
- Node.js 18+
- npm 9+ veya yarn 3+
- Git 2.40+
- Docker (opsiyonel)
```

### Hızlı Başlangıç

```bash
# Repository klonla
git clone https://github.com/yalmaz665-dotcom/nexus-yahya.git
cd nexus-yahya

# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Tarayıcıda aç
# http://localhost:3000
```

### Environment Kurulumu

```bash
# .env.local dosyası oluştur
cp .env.example .env.local

# Değişkenleri güncelle
OPENAI_API_KEY=your_api_key_here
DATABASE_URL=your_database_url
GITHUB_TOKEN=your_github_token
VERCEL_TOKEN=your_vercel_token
```

## 🤝 Katkı

Nexus Yahya'ya katkı yapmak istiyorsanız:

1. **Fork** edin
2. **Feature branch** oluşturun (`git checkout -b feature/YeniOzellik`)
3. **Değişiklikleri commit** edin (`git commit -m 'Yeni özellik eklendi'`)
4. **Branch'i push** edin (`git push origin feature/YeniOzellik`)
5. **Pull Request** açın

Detaylar için [CONTRIBUTING.md](./CONTRIBUTING.md) dosyasına bakın.

---

## 📝 Commit Mesajı Standardı

```
[TYPE] Title - Brief description

[BREAKING] Breaking changes (if any)

Detailed explanation...

Fixes #123
Related to #456
```

**TYPE Seçenekleri:**
- `feat:` Yeni özellik
- `fix:` Hata düzeltmesi
- `docs:` Dokümantasyon
- `style:` Kod stili
- `refactor:` Kod refaktoring
- `perf:` Performance iyileştirmesi
- `test:` Test eklenmesi
- `chore:` Yapılandırma
